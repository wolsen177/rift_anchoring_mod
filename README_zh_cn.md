# Rift Anchoring（裂隙锚定）

> 🌐 [English](README.md) | 中文文档

**Rift Anchoring** 是一个 Minecraft NeoForge 1.21.1 模组，通过两种多方块结构实现永久加载区块：**裂隙重生锚**（核心加载器）和**裂隙磁石**（扩展加载器），附带完整的视觉效果和配置选项。

---

## 功能特性

### 裂隙重生锚（核心加载器）

- **3×3 黑曜石底座 + 重生锚** — 在地面铺设 3×3 实心黑曜石平台，在中心方块上方放置重生锚
- **永久区块加载** — 手持无限萤石右键重生锚，即可永久强制加载整个区块
- **无限萤石合成**（可配置方式）：
  - **铁砧**：萤石 + 附魔书（消耗 5 级经验）
  - **锻造台**：萤石 + 下界之星 + 下界合金升级模板（不消耗经验）
  - **两种方式**（默认）：两种配方均可使用
- **禁止设置重生点** — 处于合法多方块结构内的重生锚无法设置玩家出生点
- **持续视觉反馈** — 激活期间持续播放粒子效果
- **底座破坏惩罚** — 黑曜石底座被破坏时，能量快速消耗，粒子效果加剧
- **可配置能量消耗间隔** — 能量间隔可调（默认：每级充能每小时消耗一次）

### 裂隙磁石（扩展加载器）

- **扩展区块加载** — 裂隙磁石必须放置在已被激活的裂隙重生锚加载的区块**相邻**的区块中（共享边或角）
- **3×3 黑曜石底座 + 磁石** — 与重生锚相同的结构，中心放置磁石
- **自动激活** — 结构完整时自动激活，伴随粒子效果和音效
- **铁锭合成配方** — 移植 Minecraft 1.21.5 的磁石配方（8 铁锭 + 1 錾制石砖）。原版下界合金配方同样可用
- **锚定指南针绑定**：
  1. 首先将萤石升级为**无限萤石**（见上方合成方式）
  2. 在**铁砧**中，将无限萤石 + 附魔书组合 → 萤石获得特殊属性
  3. 手持升级后的萤石**右键**裂隙重生锚激活区块加载
  4. 制作一个普通的**追溯指针**（Recovery Compass，原版物品）
  5. 手持追溯指针**右键**已激活的裂隙磁石 → 消耗追溯指针，生成绑定的**锚定指南针**
  6. 锚定指南针始终指向其绑定的磁石，并在tooltip中显示坐标和距离
- **扩展限制**：每个裂隙重生锚最多支持在其 **5×5 区块半径**（含自身区块）内管理 **25** 个裂隙磁石
- **破坏惩罚** — 磁石被破坏时，其区块立即释放；所有绑定该磁石的锚定指南针解除绑定（物品 Lore 重置）

### 区块调试魔杖

- **右键任意方块** — 显示区块加载状态、强制加载等级和附近已加载区块
- **右键激活的裂隙重生锚** — 显示锚点详情（能量、无限模式、剩余时间）
- **右键激活的裂隙磁石** — 显示绑定的主锚（如果有）以及关联的指南针数量

| NeoForge  | 21.1.222+   |
| Java      | 21          |

## 安装方法

1. 为 Minecraft 1.21.1 安装 **NeoForge 21.1.222+**
2. 从 [Releases](https://github.com/yourusername/RiftAnchoring/releases) 页面下载最新版本 JAR
3. 将 JAR 文件放入 `.minecraft/mods/` 文件夹
4. 启动游戏

## 使用指南

### 裂隙重生锚

1. 在地面搭建 **3×3 黑曜石平台**
2. 在中心方块上方放置**重生锚**
3. 制作**无限萤石**（见上方合成方式）
4. 手持无限萤石**右键**重生锚 → 激活区块加载
5. 激活后，重生锚上方会出现粒子效果
6. 破坏黑曜石底座会停止区块加载并触发消耗惩罚

### 裂隙磁石

1. 确保你有一个**激活的裂隙重生锚**正在加载其所属区块
2. 找到一个**相邻区块**（与锚点区块共享边或角）
3. 搭建 3×3 黑曜石平台，在中心放置**磁石** → 结构自动激活
4. 制作一把**追溯指针**（原版物品）
5. 手持追溯指针**右键**激活的裂隙磁石 → 消耗追溯指针，获得**锚定指南针**
6. 锚定指南针始终指向该磁石并显示坐标

### 无限萤石合成

**方式一 — 铁砧**（消耗 5 级经验）：
将**萤石**和**附魔书**放入铁砧。

**方式二 — 锻造台**（不消耗经验）：
将**萤石**、**下界之星**和**下界合金升级锻造模板**放入锻造台。

### 破坏裂隙磁石

- 其区块立即停止强制加载
- 所有绑定该磁石的锚定指南针解除绑定（物品 Lore 重置）
- 播放破碎音效并产生粒子爆发

## 配置

配置文件位于 `.minecraft/config/rift-anchoring-common.toml`：

```toml
# 能量消耗间隔，单位：秒（默认：3600 = 每级充能每小时消耗一次）
energyIntervalSeconds = 3600

# 无限萤石合成方式："anvil"（铁砧）、"smithing"（锻造台）或 "both"（两者，默认）
infiniteGlowstoneMethod = "both"

# 磁石合成配方："iron"（1.21.5 铁锭配方）、"netherite"（原版）或 "both"（两者，默认）
lodestoneRecipe = "both"

# 每个裂隙重生锚最多支持的裂隙磁石数量（默认：25，最大：25）
maxLodestonesPerAnchor = 25

# 启用裂隙磁石操作的详细调试日志输出（默认：false）
enableLodestoneDebugLog = false

[debug]
# 启用区块调试魔杖物品（默认：true）
enableDebugWand = true
```
